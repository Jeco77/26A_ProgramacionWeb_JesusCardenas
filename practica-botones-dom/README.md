## Alumno
Jesus Eduardo Cardenas Ortega

## Descripción
Proyecto en TypeScript que simula botones usando elementos HTML que originalmente no fueron diseñados para funcionar como botones.

## Tecnologías usadas
- HTML
- CSS
- TypeScript
- Bun

## Instalación

```bash
bun install
```

## Compilar proyecto

```bash
bun build ./src/main.ts --outdir ./dist --target browser
```

## Ejecutar servidor

```bash
bunx http-server
```

## Funcionamiento

Los siguientes elementos fueron convertidos en botones:

- div
- span
- img
- p
- a
- article
- header
- li
- section

Cada elemento:
- responde a click
- muestra mensajes en consola
- tiene hover
- tiene efecto active
